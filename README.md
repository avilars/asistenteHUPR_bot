# 🤖 Asistente HUPR Bot

Bot Rasa para asistencia y comunicación en el Servicio de Ginecología y Obstetricia.

Este Space está configurado para ejecutarse en Hugging Face con Docker.

### 🚀 Ejecución
El contenedor se basa en la imagen oficial de Rasa 3.6 y escucha en el puerto 7860.

Puedes probarlo desde la API REST:
https://avilars-asistenteHUPR_bot.hf.space/webhooks/rest/webhook
